Screenshots in the walkthrough and manual are real captures of the documentation capture build (`dist-capture`), made by the Playwright scripts in `edupulse-app/tests/snapshots/`. This build includes preview personas and sample academic data; some manual tasks exercise real documents and local models. Section 08 of the walkthrough distinguishes refreshed synthetic UI fixtures from its earlier hosted account validation. [Capture-run metadata](capture-runs/README.md) records executed suites, source/build provenance and image hashes. Charts and diagrams remain in *session-generated*; release validation evidence is recorded in each version folder.

**Strict requirement:** every feature change updates its screenshots and documentation in the same commit. Changed screenshots are replaced, stale text is edited, removed screens are taken out and new screens are added. A commit hook, `npm run verify` and CI enforce this. See the [documentation policy](DOCUMENTATION-POLICY.md) and the [source-to-documentation map](doc-map.json).

The [6 November workspace-status update](versions/2026-11-06-workspace-status-settings/README.md) removes the page-wide save banner and keeps backup, retry and conflict recovery in **Settings → Data & Privacy**. Validation and publishing status are recorded in the release.

That release shipped from `b380f91` and passed its local release gate, focused browser checks and public hosted checks. Saved content and instructor editing remain available; refreshed examples distinguish synthetic display checks from real model-generation evidence.

The [3 November completion release](versions/2026-11-03-claude-completion/README.md) finished the pending account dashboards and outline/editor work, fixed Pulse's named-role navigation and clarified direct Anthropic failures. Its local release gate passed 199 unit/integration tests; 207 runnable browser cases passed across the broad run and corrected reruns, with 19 declared skips. That release shipped from `80b55c6` and passed public hosted checks. See its release validation for the account-specific Anthropic and GitHub billing limits.
