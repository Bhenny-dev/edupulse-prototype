Check the full syllabus, factual details and source locations before use. No connected-provider or retained-passage RAG verification was run.

Foreign Language uses a proposed Japanese track; Elective 2 uses a proposed quality-engineering track. Instructors must confirm or replace those choices before syllabus approval. The active Advanced Mobile offering follows its saved information-systems outline, while other starters follow recorded curriculum outcomes.
