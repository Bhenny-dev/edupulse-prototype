# System Admin role monitoring

1. Sign in as a designated System Admin.
2. Choose **Dean**, **Program Coordinator**, **Instructor**, or **Student** in the navigation. This monitors the role while retaining your admin identity.
3. Use the clickable summary cards or tabs to inspect accounts, recorded activity, AI runs or shared health. Search **Accounts** by name or username.
4. Choose **Refresh** for fresh records. Focus, timers and reconnects do not reload the page.
5. Reload the browser to retain the role and tab. Account authorization is verified again; no support entry, save or inference is replayed.
6. To inspect a named academic workspace, choose **Choose account view**, then explicitly select a person in the account picker.

See [screens and data-window boundaries](../../system-walkthrough/07-system-admin/README.md#role-monitoring-stations).
