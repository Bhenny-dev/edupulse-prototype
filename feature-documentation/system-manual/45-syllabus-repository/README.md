# 45 - Instructor syllabus repository

**Who:** signed-in instructors and a freshly authorized Admin instructor support view. **Where:** Syllabus in the main navigation, separate from Course.

## Keep owned and received syllabi

My Syllabus lists every saved owned syllabus; a previous seeded teaching-set limit no longer hides other records. Received read-only copies appear under Shared with me and name the sending instructor. View, edit, sharing, review and saved suspension/deletion retain their existing rules. A private draft is not a course assignment.

## Import a draft PDF or DOCX

1. Choose Upload draft PDF or DOCX in My Syllabus. Syllabus Builder opens with the draft file chooser focused.
2. Choose a file or drop it in the upload area. The current limit is 2 MB; readable PDFs/DOCX files and supported scanned PDFs use the existing extraction/OCR path.
3. Review Extracted Sections Preview and choose Use This Syllabus. Check the seven editable sections against the source. Upload/extraction alone does not save, approve or activate the syllabus.
4. Choose Save as Drafted. The same saved ID remains in the builder URL and reopens on deliberate reload. Unsaved form content is not restored as a navigation hint.
5. Choose Download PDF draft to rebuild a PDF from the form. This is the reviewed structured draft, not a claim that the source PDF layout or signatures were reproduced. My Syllabus opens the saved record and Edit in Builder resumes it.

Build a syllabus starts the same builder without an imported document. Existing explicit AI drafting, validation, Checked station and offline approval remain available. Opening/reloading a tab or editor never generates, publishes, shares or submits anything.

## Share and receive

Share syllabus selects another registered instructor. Shared Repository lists only outgoing shares. It loads on page entry and after your sharing actions, with no routine Refresh shared syllabi button. Reopen or reload the page to fetch later incoming copies; a failed read offers its actual error and Retry. Received copies remain in My Syllabus with sender provenance; use a copy as a draft or complete the existing separate acknowledgment for an authorized retained approved copy. Courseware, private source copies and another instructor's workspace are not shared. See [the sharing and suspension rules](../36-instructor-syllabi/README.md).

## Use one approved syllabus for teaching

Course lists the Dean/Program Coordinator's actual teaching assignments. Open a course to add its approved same-course syllabus only while no active basis exists, using local approved PDF/DOCX intake or a matching approved shared copy. That syllabus supplies the course's chronological weeks, topics, teaching materials and assessments. The repository and builder are not course tabs. Another draft in the repository does not add a course to the load or replace its active teaching basis. Revising an active syllabus retains the existing withdrawal/reapproval behavior.

Direct /syllabus tab/edit links and former nested course syllabus links resolve to the separate repository. Current authorization is rechecked before displaying saved records; unavailable targets fail closed. The owner has paused documentation screenshot recapture; the release record distinguishes controlled browser checks from hosted account or production persistence evidence.
