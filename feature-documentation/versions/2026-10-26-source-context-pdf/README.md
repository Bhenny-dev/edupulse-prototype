# Source-aware Pulse, PDF fidelity and focused editing

This release corrects dropped PDF table lines, lost page-upload context, fixed buddy dialogue and a panel that covered the edited section. It adds real PDF downloads for syllabus drafts/approval copies, learning documents and generated responses.

The actual local IT-202.pdf was used for extraction verification; personal names and source bytes are not included in the repository. Public capture fixtures use invented academic examples. See [validation](validation/results.md) and the updated manuals for supported flows and limits.
