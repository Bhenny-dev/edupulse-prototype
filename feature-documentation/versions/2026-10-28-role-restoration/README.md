# Role-specific account section restoration

Working change, 28 October 2026. No commit, hosted deployment or production-data migration is claimed.

Eight authenticated page branches had replaced the richer role pages with a small generic record view. This change rebuilds role dashboards, performance and monitoring tabs/charts/matrices, oversight, records intake, course-loading detail and student readers around the existing authorized academic projection. The System Admin console and instructor authoring remain separate.

Charts use actual raw attempts, enrollment, publications and first opens. No fabricated topic mastery, due dates, qualification records or institutional grades are introduced. Record notices now populate authenticated accounts; read state remains per account/role on the device. Dark surfaces, semantic shades and chart tooltips are corrected, and laptop navigation no longer overflows.

Private CSV intake is additive to the existing revision-checked workspace. It supports preview/rejections, stable-key updates, persisted history and template/CSV downloads, without turning a Dean's import into another account's enrollment or official course assignment.
