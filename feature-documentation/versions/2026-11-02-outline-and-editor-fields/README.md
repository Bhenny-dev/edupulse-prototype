# One Course Outline table, fields that fit their text and visible generation problems

Release record, 2 November 2026.

- **One Course Outline table.** Section 5 of the Syllabus Builder holds every week in one table, under a **Midterm** (Weeks 1–9) and a **Finals** (Weeks 10–18) row heading, instead of one table per term. On a desktop the section is wider than the page column (up to 1,760 px, less an open Pulse panel), so every column shows at once and the column headings stay under the top bar while the page scrolls. The expanded view and narrower windows keep the table's own scroll region. The table no longer pushes the builder page wider than its column.
- **Fields that fit their text.** Outline cells, document sections in the courseware editor and assessment answer explanations grow with their text. None scrolls inside a fixed box or shows a resize handle.
- **Generation problems stay on screen.** A course opened with no provider or on-device model says **Pulse AI is not set up yet** with **Set up Pulse AI**. A generation that cannot run shows **Generation did not finish**, the reason, **Set up Pulse AI** for connection problems and **Dismiss**, instead of a short toast.
- **Settings links.** An unknown or unavailable `?tab=` value opens **Account** instead of an empty page, and **Set up Pulse AI** opens **AI & Knowledge** directly.

Documentation captures pin the outline headings in place while photographing a section taller than the window; in use they stick under the top bar.
