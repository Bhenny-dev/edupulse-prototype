# Combined Courseware workspace — 6 November 2026

Courseware now uses one course list and weekly workspace instead of separate My Courseware and Courseware Builder tabs. Course rows retain instructor, status, generated/expected counts, progress and teaching weeks. **View** opens saved content; **Generate** remains on empty courses and teaching weeks. Older tab/course/week links remain compatible.

Three-dot menus retain course and week generation, missing-content generation, bulk review, document/presentation views, item checking, publication and delivery settings. All saved item statuses can be viewed. Selection checkboxes and **Check Selected** remain available. Examination weeks have no generation control. A course becomes Complete only when all teaching weeks have all three published item types.

Generation fills missing items without replacing existing work. Regenerating drafts preserves delivery dates and assessment rules; checked/published items are protected. The same workspace save and authorized publication flow remain in use. Signed-in student/management views keep their existing academic record boundaries. No endpoint, database migration, provider configuration or role change is included.

The [manual](../../system-manual/03-courseware-generation-and-review/README.md), [role walkthrough](../../system-walkthrough/04-instructor/README.md) and capture pipeline describe the combined controls. New courseware flow captures use synthetic provider/account/workspace transport; prior real local-generation evidence is archived separately. See [validation](validation/results.md).
