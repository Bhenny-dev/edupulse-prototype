# Instructor summary-card navigation

8 November 2026. **My Courses**, **Active Syllabi**, **Drafts to Review** and **Published Items** now navigate through native links, including keyboard activation and browser Back. Active syllabi and draft/published course lists have explicit filters and **Show all** controls. Switching Syllabus tabs clears its filter so new drafts remain visible.

The existing course-generation eligibility, review/publish actions, permissions and stored records are preserved. [Manual 22](../../system-manual/22-dashboard-summary-navigation/README.md) shows the current screens; [validation](validation/results.md) records checks and scope.

Released to [production](https://edupulse-prototype.vercel.app) from feature commit `54088bd`, with the updated landing page included. The deployment reached **Ready** and public smoke checks passed; see the [release receipt](validation/production-smoke.json).
