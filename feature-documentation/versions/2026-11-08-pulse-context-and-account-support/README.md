# Pulse context and account support - 8 November 2026

Pulse distinguishes casual conversation, authorized account records, product help, selected-document work and public factual research. Live account context is read under server permissions; automatic academic pagination removes the previous silent 1,000-row limit. Supabase stores scoped completed-run handoffs for agent continuity, respecting automatic-memory opt-out and conversation deletion.

System Admin role selection now offers a searchable account picker with student year, department and program filters. Academic data and permitted changes use the selected person's row-level permissions. The admin retains their own sign-in, provider, private conversations and knowledge library. Support changes are audited, and student support previews never create learner activity or assessment attempts.

The release preserves the restored interface and the existing own-account role view. It does not publish unchecked teaching content or fabricate student progress.
