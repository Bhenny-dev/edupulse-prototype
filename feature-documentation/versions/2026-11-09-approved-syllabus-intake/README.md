# Approved syllabus course intake · 9 November 2026

Instructors can choose **Upload syllabi** from empty or populated Course views. **My Syllabus** accepts approved PDF/DOCX copies directly, previews the extracted outline and retains the source file. Explicit attestation and selection save the active syllabus before opening its course. The five-station indicator is removed; optional draft preparation, versions and offline approval actions remain.

See [Manual 30](../../system-manual/30-approved-syllabus-intake/README.md), [backend contract](../../backend-system/README.md#approved-syllabus-course-intake-9-november-2026) and [validation](validation/results.md). No API, database schema, authorization, enrollment, publication or grade-computation change is required.
