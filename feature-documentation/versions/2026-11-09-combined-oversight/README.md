# Combined syllabus and delivery oversight - 9 November 2026

Academic Oversight now has one **Syllabus & Delivery** tab with saved stations, released-courseware charts and a consolidated filtered table/CSV. Student Oversight, Alerts and the Dean-only Review Inbox remain. Separate course IDs survive duplicate codes; teaching-week coverage excludes inactive/future and unplanned/examination publications. Old tab links remain compatible.

See [Manual 29](../../system-manual/29-combined-oversight/README.md), the [backend contract](../../backend-system/README.md#combined-academic-oversight-9-november-2026) and [validation](validation/results.md). No database, approval, grading, account or student-activity write is introduced.
