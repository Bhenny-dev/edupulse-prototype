# Readable outline selectors - 9 November 2026

Teaching-material and assessment-type choices now use a searchable viewport-bounded panel outside the scrolling outline. Grouped checkbox rows, visible counts, removable chips and explicit dismissal replace clipped and overlapping options. Existing values, week identity, activity/assessment text and approval controls remain.

See [Manual 28](../../system-manual/28-outline-selectors/README.md) and [validation](validation/results.md). No dependency, API or database change is required. This release also corrects terminal-encoding artifacts in recently authored documentation headings, ranges and punctuation without changing their feature contracts.
