# Public Pulse information search — 9 November 2026

Public Pulse now ranks relevant local descriptions instead of answering from whichever FAQ contains an incidental word. A student statement after a named person keeps that person in context. Misspelled feature and role questions offer a correction and a relevant answer without an AI key or chat API call.

The curated index covers public staff roles, project credits, students' capabilities, syllabus intake, outline-driven materials, rosters, releases, results, PDF controls and provider boundaries. It contains no live student directory or credentials. Self-contained questions reset the topic; unknown people and unverified social identities remain explicit limitations. Existing agent selection, moods, room rendering and assessment-answer restrictions remain. Agent speech bubbles now use the public page's day/night surface and text colors so night replies stay readable.

See [Manual 32](../../system-manual/32-public-pulse-search/README.md), the [public walkthrough](../../system-walkthrough/01-public-site/README.md) and [validation](validation/results.md). No endpoint, migration, provider configuration or authenticated authorization rule changes.
