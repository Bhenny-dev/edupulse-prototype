# System-first Pulse search - 9 November 2026

Simple questions now use a deterministic System Search agent before provider resolution. Authorized names, current records, saved authoring content, selected attachments, indexed library passages and the product guide can answer without AI credits. Name initials and small typos produce explicit suggestions; identifiers are never guessed. Complex generation keeps the existing agent/tool workflow, with local research preceding web supplementation.

When local content has no relevant match, public questions receive labelled keyless Internet suggestions. Returned Wikimedia thumbnails appear beside their source and attribution links, with a readable failed-image state. No new dependency, database schema, permission grant or account mutation is introduced.
