# Course generation and readable source copies — 10 November 2026

The reported on-device failure came from requesting `json_object` without the schema string consumed by the installed WebLLM 0.2.85 grammar path. Structured requests now include a serialized object schema; the existing graph still enforces exact content structure and completeness. String rejections from the worker become Error objects before LangGraph annotates them. Output-limit and cancellation failures remain unsuccessful requests.

Retained-source review now uses the existing safe Markdown renderer. Its title excludes a redundant embedded URL, while **Source details** retains the complete bibliography, saved date, pages and checksum. The dialog has one scrolling content region and visible close/download actions. **Download PDF** creates a formatted reading copy with retained-source metadata; **Download retained copy** preserves the original bytes and checksum. This change neither rewrites the source nor changes its private access rules.

The existing WMAD 304 five-week record was separately repaired from its matching retained original to the full title and 18 printed weeks, with unchanged original bytes and no generated items or learner activity. That persisted execution is recorded in the [compatibility release](../2026-11-09-syllabus-file-compatibility/validation/results.md).

See [Manual 31](../../system-manual/31-retained-syllabus-sources/README.md) and [validation](validation/results.md). Account self-recognition, reload restoration, actual approved-course seeding, explicit syllabus sharing and block delivery remain separate unfinished work.
