# Labelled progress on registered test accounts

Registered BSIT accounts can exercise actual delivery, material access and server scoring while retaining an explicit **Pipeline test** provenance label. Student progress and instructor monitoring use the same persisted records. The default view includes both student activity and pipeline tests; the activity filter isolates either category and exported attempt/access rows include the label.

Version-bound test authorization requires the publication's current instructor and an active registered, enrolled student. The database labels future inserts inside the ordinary learner transactions. Existing genuine activity cannot be relabelled. This does not bypass enrollment, release dates, deadlines, timers, answer-key secrecy, attempt limits or support-view restrictions.
