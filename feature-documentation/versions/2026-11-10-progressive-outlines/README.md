# Progressive syllabus outlines

Hosted and on-device outline preparation now use one teaching week per validated step. Completed weeks appear immediately in the mounted builder, remain reviewable after a later failure, and can be placed in the form without overwriting manually changed weeks. Placement remains separate from saving and publication.

Same-course syllabus patterns in the current accessible workspace are ranked without a model, reduced to bounded sequence windows, and used before generic public research. Explicit research can supplement them; source-only restrictions remain authoritative. Persistent shared-repository expansion and full reload restoration remain separate open tasks.
