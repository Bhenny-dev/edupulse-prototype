# Reference link and file intake

Section 7 now accepts source links and readable files rather than manual bibliographic fields. Explicit HTML citation/DC/JSON-LD, PDF/Word document metadata and simple text front matter provide available details; missing metadata is not guessed. Readable copies are retained before an independently retryable private indexing step.

The existing source archive and knowledge pipeline supply immutable originals, version-bound citation metadata, keyword/pgvector retrieval and formatted exports. Legacy entries remain usable. Catalog/search listings stay metadata-only, no paid provider is needed for ingestion, and private account ownership is preserved.
