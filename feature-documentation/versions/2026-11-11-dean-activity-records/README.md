# Dean activity records - 11 November 2026

The Dean opens Course, Instructors and Students directly from four-item navigation. Dashboard and other Dean summaries share an accessible card component and open matching records, filters or dialogs.

Course contains read-only course records, loads, student class lists and syllabi. The owner's requested removal of Dean import, Templates, History and block-edit controls preserves underlying records and Associate Dean intake. Students groups blocks by recorded year and opens searchable, downloadable student lists. Instructor dialogs expose saved course activity. Oversight, offline review and read-only Performance remain reachable.

View hints store bounded detail references scoped to the actual account, role and support subject. Fresh authorized records determine the restored dialog. Navigation/reload does not replay commands or inference. No schema migration or backend permission change is required.
