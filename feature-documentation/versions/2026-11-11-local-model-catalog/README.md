# Downloadable local model catalog

Settings now offers twelve WebLLM-compatible choices across five model families, preserving the two previous IDs and caches. Users can inspect weight sizes, memory estimates, model cards/licenses, complete cached downloads and the independently loaded engine. Selected cached removal and scoped reload restoration retain existing provider workflows.

See [Manual 8](../../system-manual/08-ai-connections/README.md), [artifact metadata](../../backend-system/local-model-catalog.json) and [validation](validation/results.md). Free downloadable weights remain subject to their publisher licenses and device requirements.
