# Scoped outline sections and source-based courseware

11 November 2026. Local implementation; no deployment performed.

The owner requested simplified Course Outline columns, one Contents field, no teaching-material selector, seven supported assessment choices, multiple sections within a week and shared sections across weeks. The updated flow preserves section IDs, unique calendar slots, exams and existing records while aligning new teaching/assessment output with the selected scopes and readable references.

Teaching files can be attached as instructor drafts. Separate section assessments follow the generated/attached teaching output, with explicit requested formats and instructor marking for written/practical work. A selected passage can locate an exact or related excerpt in its private retained source copies, show the matching sentence, and send the generated passage plus source basis to Pulse explicitly. Reload restores navigation without repeating inference.
