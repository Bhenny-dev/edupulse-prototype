# Courseware editor width and wrapping

Long question/option, material heading and slide point fields now wrap and grow. Instructor editors use available width up to 1200 px. Presentation editing allows vertical scrolling instead of clipping inside a fixed slide ratio. Reading/print/PDF layout and content saves are unchanged. Controlled browser checks measure scroll/client bounds for long content; captures show synthetic examples.
