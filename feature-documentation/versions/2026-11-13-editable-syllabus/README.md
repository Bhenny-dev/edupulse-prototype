# Direct editable syllabus workspace

Validated syllabus edits populate open draft fields directly. Owned drafts reopen as editable targets, saving stays in the builder, and bounded conversation context supports the next week or remaining weeks. Optional changes/source review and next actions replace generated-syllabus confirmation cards; approval and other workflows retain their explicit controls.
