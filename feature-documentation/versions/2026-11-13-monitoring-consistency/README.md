# Consistent monitoring and independent activity

Instructor monitoring reuses Dashboard SummaryCard, opens short roster/result/delivery actions from three-dot menus, and restores its authorized menu/filter/page references without replaying writes. Only student-recorded attempts, opens, sessions and reading confirmations supply its statistics. Inactive and unreleased courses explain their delivery state.
