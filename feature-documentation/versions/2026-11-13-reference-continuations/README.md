# Complete reference entries and source discovery

Wrapped book titles and next-line URLs stay attached. Source lists separate bibliographic fields and readable text from catalog metadata. Unlinked books receive a bounded online catalog search; accessible public sources and uploads can be retained and indexed privately, with edition discrepancies and read/index failures disclosed.
