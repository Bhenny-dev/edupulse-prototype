# Instructor course workspace and system-first chat

The signed-in Instructor dashboard summarizes current Dean-loaded courses and enrolled students in those blocks. Course cards include assigned courses awaiting a syllabus. Syllabus management is inside the selected course; old syllabus URLs redirect to this location.

An approved local/shared syllabus opens chronological weeks and topics. Each topic supports ordered documents, private files or links, intervening assessments and a final overall assessment. Extracted activities/assessment labels provide context. AI is invoked only for explicit content authoring; readable teaching content and retained sources remain required. Existing unapproved drafts remain reviewable without publication.

Week dragging and keyboard move controls retain chronological week labels, fixed exams, stable section IDs, and content association. Affected delivered items return to drafts for review, preserving historical scores; partial generation must finish or be explicitly discarded before moving its weeks. Real current enrolled-learner activity supplies progress pills; missing results remain missing.

Ordinary chat uses system rules, authorized records and typo matching without model fallback. System citations open a freshly authorized source dialog and offer confirmed navigation to the related course/material. Reload restores navigation references only and cannot replay learner activity, inference, publication or saves. Current dictation and playback remain available.

See [Manual 44](../../system-manual/44-instructor-course-workspace/README.md) and [validation](validation/results.md). Private storage migration `20261114100000` is additive; no business records were seeded or rewritten for this task.
