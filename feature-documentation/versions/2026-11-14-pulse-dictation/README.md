# One-button Pulse dictation - 14 November 2026

Pulse now records from the microphone icon beside the input field. The same position becomes Stop recording, then Cancel transcription while the clip is processed. Stopping places a Filipino, English or mixed-language transcript in the editable draft; only Send submits it. Removed language and mode controls cannot restore automatic sending from older preferences.

The new bounded transient transcription action uses the actual account's active OpenRouter/OpenAI/Gemini connection. It does not store audio or change the selected chat model. Existing permissions, encrypted credentials, leases, rate limits and cancellation apply. Reply playback remains available and can also be stopped from the composer.
