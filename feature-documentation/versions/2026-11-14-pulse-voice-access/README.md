# Pulse voice access — 14 November 2026

Pulse's microphone entry was hidden until enabled through its options menu. Reply playback was available only during voice conversations. The microphone control is now always visible beside the message box, and each Pulse text reply offers **Read aloud / Stop reading** without enabling recognition or requesting another AI answer.

The existing browser speech engine, account/view language preferences, bounded spoken excerpt and cancellation lifecycle are reused. Listening still needs an explicit **Start listening** action. Opening, reopening and reloading do not start audio. Unsupported or failed playback explains itself while retaining text chat.
