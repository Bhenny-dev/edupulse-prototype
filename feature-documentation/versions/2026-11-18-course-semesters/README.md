# Semester-scoped courses and instructor class lists

Add/Edit Course use code, title and units. The shared selected semester supplies the period. Dean and Program Coordinator load courses only; instructors add block class lists by file or individual registered-student selection. Completed periods are view-only. Independent replacement packages and actual student history remain retained.
