# Department home blocks and first-year corrections

All 2,286 existing active students now have home placements across six departments and 23 programs: 109 blocks, each at most 35 students. The confirmed 2027-x-xxxx intake rule corrected 30 year values; all 485 matching IDs are Year 1. Other recorded year levels remain unchanged. This preserves 416 valid existing placements and moves one existing placement into its corrected first-year block.

Home blocks appear in the Dean/Program Coordinator directory even without course enrollments, with a Department filter. Students can see their own home block on Dashboard before courses are loaded. Individual registered-student selection remains available across departments from an instructor-assigned course. It is not a nationality field or automatic course enrollment.
