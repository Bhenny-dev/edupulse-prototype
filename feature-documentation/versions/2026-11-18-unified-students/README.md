# Unified Students directory

Students now uses one page across all departments, with search, department, year and block filters. Selecting a department reveals its year-grouped section cards; choosing a card filters the same student table. Filters and pagination survive reload. CSV exports all filtered matches, with existing spreadsheet escaping.

Existing account actions, irregular-student review, student details and previous-semester restrictions remain. No accounts, home placements, course enrollments, teaching loads or learner activity are changed.
