# 27 November 2026 — Class Stream and teaching plan

The instructor class opens in **Stream** with saved publications, announcements, the class code and upcoming work. **Teaching Materials & Assessments** contains the working weeks and courseware, with existing check, publish and revision controls. The week editor preserves examination slots, saved courseware and the reference outline. Week removal is available for empty teaching weeks.

Posts can appear before or inside a week or topic. Students see them according to their existing class membership. The migration adds the placement fields to the current announcement command.
