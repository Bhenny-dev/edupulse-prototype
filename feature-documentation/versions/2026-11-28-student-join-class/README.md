# 28 November 2026 · Student Home class joining

**Join Class** appears beside **Academic term** on Student Home, including before the first enrollment. Students enter the seven-character code from their instructor, review the matching course and section, and confirm enrollment. **Admin · Student** opens guidance for the student's own sign-in.
